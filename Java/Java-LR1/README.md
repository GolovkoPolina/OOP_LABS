# Лабораторная №1 — Товары и склад (Java)

Вариант 2, перенос ЛР1 с C# на Java. Четыре класса в пакете `laba1`:
- `Dimensions` — неизменяемые вес, объём, признак хрупкости.
- `Product` — товар, инварианты, приход, отгрузка, расчёт цены с налогом.
- `Warehouse` — склад, поиск по артикулу, отгрузка, низкий остаток, стоимость.
- `Skladik` — точка входа (`main`) и демонстрация работы.

## Запуск

Открыть в VS Code **эту папку** (где лежит `pom.xml`), а не `src/main/java/laba1`.

Если установлен Maven:
```powershell
mvn compile exec:java
```

Или без Maven, из папки проекта в PowerShell:
```powershell
javac -encoding UTF-8 -d out src\main\java\laba1\*.java; if ($LASTEXITCODE -eq 0) { java -cp out laba1.Skladik }
```

Для компиляции нужна Java JDK 17 или новее.
