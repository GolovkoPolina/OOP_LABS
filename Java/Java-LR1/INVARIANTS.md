# Инварианты ЛР1 — основа будущих тестов ЛР3

| Класс | Правило | Пример допустимого | Пример недопустимого |
|---|---|---|---|
| Product | Артикул непустой, неизменяемый | `"A001"` | `""`, `null` |
| Product | Название непустое | `"Мышь"` | `" "`, `null` |
| Product | Цена конечная, строго больше нуля | `1.0` | `0`, `-1`, `NaN` |
| Product | Количество неотрицательное | `0` | `-1` |
| Product | Минимальный остаток неотрицательный | `0` | `-1` |
| Product | Dimensions не равен null | `new Dimensions(1,1,false)` | `null` |
| Product | Приход строго положительный | `dose(1)` | `dose(0)` |
| Product | Отгрузка строго положительная и не больше остатка | `ship(1)` при наличии 1 | `ship(2)` при наличии 1 |
| Product | Новая цена строго положительная | `changePrice(100)` | `changePrice(0)` |
| Dimensions | Вес, объём конечные и строго положительные | `1.0`, `0.1` | `0`, `NaN`, `Infinity` |
| Dimensions | Поля неизменяемые | создание нового объекта | прямое изменение невозможно |
| Warehouse | Вместимость строго положительная | `new Warehouse(1)` | `new Warehouse(0)` |
| Warehouse | Нельзя добавить `null`, повторный артикул или сверх вместимости | уникальный товар | дубль, переполнение |
| Warehouse | Массив наружу выдаётся как копия | `getProducts()` | изменения копии не меняют склад |

Все тесты на модульность будут создаваться в отдельной ЛР3; этот файл — список проверяемых правил.
